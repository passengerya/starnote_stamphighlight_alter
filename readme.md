# PDF Stamp → Highlight & Overlay 工具

将 StarNote 导出的透明 `/Stamp` 批注转换为 `/Highlight` 高亮，并可将转换结果按页覆盖到另一份 PDF。内置 Web UI 方便可视化选页、映射与下载，也可命令行批处理。

## 功能
- 批注转换：仅处理透明度 < 1 的 `/Stamp`，生成圆角高亮（内置 AP，兼容主流阅读器），保持其他批注不变。
- 选页灵活：输入页码范围（如 `1,3,5-7`）或在缩略图上多选；按钮实时显示来源文件名。
- 覆盖输出：上传目标 PDF，选择目标页并可指定来源页，一一映射后生成新文件，沿用目标文件名。
- 可视预览：来源/目标缩略图并排网格显示，点击即可选中；右键缩略图可弹出原图放大预览并悬浮显示。
- CLI 支持：命令行批量转换，支持选页。

## 快速开始
```bash
pip install -r requirements.txt
python app.py
# 浏览器访问 http://localhost:5000
```

## Web 操作要点
1) 导入来源 PDF：按钮文字显示文件名。可在缩略图点击选页，或在“批量选择”输入范围。
2) 转换下载：  
   - “处理选中页” 仅处理已选页；  
   - “处理全部” 处理所有页；  
   - 下载命名：`来源文件名_convert.pdf`。
3) 覆盖到目标 PDF：  
   - 选择“覆盖目标”文件后出现目标预览，点击选目标页或输入范围；  
   - “覆盖来源页码”可选，不填则默认沿用来源选页或与目标页相同；  
   - 点击“转换并覆盖”后下载文件，使用目标原文件名。
4) 预览与原图：来源/目标面板横向排列自适应网格。右键缩略图选择“查看原图”可在当前页上方悬浮放大查看，支持右键/外部点击/Esc 关闭。

## CLI 用法
```bash
# 全部页
python pdf_stamp_to_highlight.py input.pdf output.pdf

# 指定页（例：1,3,5-7）
python pdf_stamp_to_highlight.py input.pdf output.pdf --pages 1,3,5-7
```
输出默认 `output.pdf`。

## 依赖
- Python 3.11+
- pikepdf
- Flask
- 前端：CDN PDF.js 3.11.174

## 备注
- 仅转换透明 `/Stamp`，其他批注保持不变。
- 支持常见绘图指令与嵌套 Form/Image，极端嵌套会被跳过。
- 生成的高亮已内嵌圆角外观，避免不同阅读器渲染差异。
