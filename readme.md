# PDF Stamp → Highlight & Overlay 工具

将 StarNote 导出的透明 `/Stamp` 批注转换为 `/Highlight` 高亮，并可将转换结果按页覆盖到另一份 PDF。内置 Web UI 方便可视化选页、映射与下载，也可命令行批处理。

## 功能
- 批注转换：仅处理透明度 < 1 的 `/Stamp`，生成圆角高亮（内置 AP，兼容主流阅读器），保持其他批注不变。
- 选页灵活：输入页码范围（如 `1,3,5-7`）或在缩略图上多选；按钮实时显示需转换 PDF 文件名。
- 覆盖输出：上传目标 PDF，选择目标页并可指定需转换 PDF 页，一一映射后生成新文件，沿用目标文件名。
- 可视预览：需转换/目标缩略图并排网格显示，点击即可选中；右键缩略图可弹出原图放大预览并悬浮显示。
- CLI 支持：命令行批量转换，支持选页。
- 矩形注释转移：在“矩形注释转移”子页面上传需转移注释 PDF 与目标 PDF，可按页匹配复制 `/Square` 注释到目标文件。

### 页面替换逻辑
- PDF 页面替换过程中，仅对目标 PDF 中指定页码的页面内容进行替换，原文件的书签结构、元数据及其他非页面相关信息均保持不变，确保文档逻辑结构完整。
- 替换操作直接在原文件上进行原地更新，不生成新文件。被替换的 PDF 文件在文件系统层面保持原有的 inode（文件引用号）不变，PDF 内部指纹（如 ID 字段等唯一标识）亦维持原样，除页面内容更新外，文件的其他属性和结构均不受影响。
- 页面内容替换采用将源页作为 Form XObject 绘制到目标页，目标页 MediaBox/CropBox/Rotate 不变，避免书签失效与坐标系漂移。
- 源/目标页尺寸不一致时按等比例缩放并居中适配（可能留白），避免裁切。
- 目标页仅保留原有 `/Square` 注释，其它注释替换为源页注释；源页注释的 `/Rect` 与 `/QuadPoints` 会按缩放/平移映射到目标页。

## 快速开始
```bash
pip install -r requirements.txt
python app.py
# 浏览器访问 http://localhost:5000
```

## Web 操作要点
1) 导入需转换 PDF：按钮文字显示文件名。可在缩略图点击选页，或在“批量选择”输入范围。
2) 转换下载：  
   - “处理选中页” 仅处理已选页；  
   - “处理全部” 处理所有页；  
   - 下载命名：`需转换文件名_convert.pdf`。
3) 覆盖到目标 PDF：  
   - 选择“覆盖目标”文件后出现目标预览，点击选目标页或输入范围；  
   - “覆盖需转换页码”可选，不填则默认沿用需转换选页或与目标页相同；  
   - 点击“转换并覆盖”后下载文件，使用目标原文件名。
4) 预览与原图：需转换/目标面板横向排列自适应网格。右键缩略图选择“查看原图”可在当前页上方悬浮放大查看，支持右键/外部点击/Esc 关闭。

### 矩形注释转移子页面
- 路径：`/transfer`，按钮入口位于首页右上角。
- 上传需转移注释 PDF 与目标 PDF，可选填源/目标页码（支持范围与多选）；为空则按对应页顺序默认匹配。
- 点击“转移矩形注释”后下载结果，保持目标文件名。

## CLI 用法
```bash
# 全部页
python pdf_stamp_to_highlight.py input.pdf output.pdf

# 指定页（例：1,3,5-7）
python pdf_stamp_to_highlight.py input.pdf output.pdf --pages 1,3,5-7
```
输出默认 `output.pdf`。

## 依赖
- Python 3.11+
- pikepdf
- Flask
- 前端：CDN PDF.js 3.11.174

## 备注
- 仅转换透明 `/Stamp`，其他批注保持不变。
- 支持常见绘图指令与嵌套 Form/Image，极端嵌套会被跳过。
- 生成的高亮已内嵌圆角外观，避免不同阅读器渲染差异。
